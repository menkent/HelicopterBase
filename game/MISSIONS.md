# Как устроена миссия

Игра — для ребёнка 4 лет, на большом мониторе/ТВ, управление геймпадом: **стик — полёт, любая кнопка — действие**.
Читать ребёнок не умеет: всё должно быть понятно по картинке, движению и звуку. Проиграть нельзя: нет таймеров, жизней, штрафов.

Каркас (диспетчер, склад, заправка, полёт, возвращение, медали) уже готов. Миссия — это только то, что происходит
**внутри зоны места на карте**: прилетел → одно или несколько нажатий кнопки действия → `ctx.done()` → ребёнок летит домой.

Каждая миссия — один файл `src/missions/<id>.js`, экспорт по умолчанию:

```js
export default {
  id: 'fire',
  /** Статичные декорации места — рисуются один раз при создании мира и видны всегда (в т.ч. издалека). */
  drawSite(scene, site) {},
  /** Ребёнок влетел в зону активной миссии. Вызывается один раз за миссию. */
  start(ctx) {
    return {
      update(dt) {},          // каждый кадр, пока вертолёт в зоне (dt — секунды)
      targets() { return [] }, // мировые точки {x,y}, где ещё нужно нажать действие (для автотестов) — обязательно
      destroy() {},           // убрать всё созданное в start (вызывается, когда вертолёт улетел из зоны после done)
    };
  },
};
```

## Что есть в `ctx`

| Поле | Что это |
|---|---|
| `scene` | `Phaser.Scene` (Phaser 3.90, глобальный `Phaser`) |
| `site` | `{x, y, r}` — центр и радиус зоны в мире (r = 520) |
| `heli` | вертолёт: `x`, `y`, `vx`, `vy`, `angle`, `flying`, `isOver(x, y, r)`, `carry(gameObject)` — подвесить на трос (объект дальше принадлежит игре, сам отнесётся в больницу при посадке — **не уничтожайте его в destroy**) |
| `input` | `actionPressed()` — true ровно в кадр нажатия; `actionHeld()`; `move` — `{x,y}` стика |
| `sfx` | `ding pop sparkle splash spray whoosh bonk glug success` — короткие синтезированные звуки |
| `fx.sparkle(x, y, tint?, count?)` | взрыв искорок |
| `layer` | `Phaser.Container` в точке (0,0) на глубине `DEPTH.missionLow`; можно класть объекты туда — он уничтожается автоматически |
| `pointAt({x,y} \| null)` | показать жёлтую стрелку-подсказку на цель (у края экрана, если цель не видна) |
| `done()` | миссия выполнена: звук успеха, большая звезда на экране, стрелка ведёт домой. Вызвать один раз |
| `depth` | `DEPTH` из `config.js`: `site 12`, `missionLow 20`, `missionHigh 30`, `shadow 40`, `carried 44`, `heli 50`, `fx 60` |

Пока миссия не выполнена, вертолёт мягко удерживается в круге зоны (r × 1.05).

## Графика

- SVG-текстуры регистрируются при импорте модуля: `registerSvg(key, svgString, w, h)` из `../art.js`.
  Ключи начинайте с id миссии: `fire_flame`, `sea_log`… Иконки и помощники — `I`, `place`, `svgDoc` из `../icons.js`.
- Готовые общие текстуры: `bunny` (зайка, его спасаем), `icon_flame icon_drop icon_tree icon_mountain icon_sun icon_wilted icon_bloom icon_moon icon_star icon_waves icon_rope icon_buoy icon_sprout icon_flashlight`, `item_<water|rope|seeds|buoy|light>`, `tree_top tree_top2` (дерево сверху), `dot` (белая точка 16px для частиц).
- Вид **сверху**, стиль — спокойный мультяшный: земля приглушённая (трава `#dde6c8`, деревья `#a9c08a`),
  яркими делаем только **интерактивные** вещи (огонь, зайка, цветы, круг).
- Камера в полёте и в зоне миссии — зум **0.55**, весь круг места виден целиком. Значит интерактивные объекты
  должны быть **крупными: 150–220 px мира**. Зона «можно нажать» — радиус **не меньше 120**.
- Когда вертолёт над целью — подсвечивайте её (пульсирующее кольцо), чтобы было ясно: «жми сейчас».
- Каждое нажатие должно давать заметный отклик: анимация + звук. Нажатие мимо — ничего страшного, без наказания.
- Миссия занимает ~1–2 минуты. 1–3 цели.

## Правила для субагентов

- Меняйте **только свой файл** `src/missions/<id>.js`. Если нужна правка общего кода — опишите её в отчёте, не делайте сами.
- Никаких внешних ресурсов и сети: всё рисуется SVG/Graphics, звуки — из `sfx`.
- Ничего не коммитьте.

## Как проверить

Сервер: `python3 -m http.server 8765 --directory game` (обычно уже запущен; проверка — `curl -sI localhost:8765`).

```bash
cd game/tools
node smoke.mjs <id> /tmp/hb-<id>     # полный цикл: диспетчер → склад → заправка → полёт → миссия (через targets()) → домой → медаль
```

Скриншоты лягут в `/tmp/hb-<id>/*.png`, их можно смотреть. В конце печатается лог ошибок браузера — он должен быть пуст
(404 на favicon и предупреждения `GL Driver` — не ошибки).

Свои сценарии — через `tools/hb.mjs` (`openGame`, `solveMission`); в браузере есть `window.__hb`:
`startMission(id)` (сразу у места миссии с предметом), `teleport(x,y)`, `hold(x,y)` / `release()` (стик), `tap()` (кнопка),
`targets()`, `missionDone()`, `state()`, `heli()`, `goHome()`. В адресе: `?test=1` (без звука и сохранений), `?mission=<id>`.
