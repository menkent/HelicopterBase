# Вертолётная база спасения

Игра для ребёнка 4 лет про розовый спасательный вертолёт: бумажная база для игры на полу + компьютерная игра с геймпадом.

**Играть:** https://menkent.github.io/HelicopterBase/

## Компьютерная игра (`game/`)

Phaser 3, вид сверху. Диспетчер выдаёт одно из 5 заданий → на складе взять нужный предмет → заправиться → полететь к месту на карте → выполнить кнопкой действия → вернуться на площадку → медаль на «Доску героя». Когда собраны все 5 медалей — праздник и новый круг.

| Миссия | Предмет |
|---|---|
| Пожар в лесу | вода |
| Спасение в горах | трос |
| Засуха в саду | семена |
| Спасение на воде | спасательный круг |
| Ночная миссия | прожектор |

Управление: геймпад (стандартная раскладка Xbox / DualSense), клавиатура — стрелки/WASD + пробел.

Локальный запуск: `game/start.command` (macOS, двойной клик) или `python3 -m http.server 8765 --directory game`.

Интерфейс миссий описан в `game/MISSIONS.md`. Автотесты — `game/tools` (playwright-core + системный Chrome).

URL-параметры: `?mission=fire` — первым дать это задание, `?test=1` — без звука и без сохранения прогресса.

## Бумажная база (`build.py` → `out/`)

`python3 build.py` генерирует SVG базы и PDF для печати на A4 (нужен Google Chrome).
