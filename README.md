# Вертолётная база спасения

Игра для ребёнка 4 лет про розовый спасательный вертолёт: бумажная база для игры на полу + компьютерная игра с геймпадом.

**Играть:** https://menkent.github.io/HelicopterBase/

## Меню игр (`game/`)

`game/index.html` — выбор игры: ← → (крестовина, стик, LB/RB, клавиатура) и любая кнопка, или мышью. Запоминает последнюю выбранную. Из игры обратно в меню — Esc или кнопка View/Share (8) на геймпаде (`game/src/menuExit.js`). Картинки карточек — `game/menu/*.jpg` (скриншоты из автотестов).

## Компьютерная игра «База спасения» (`game/base/`)

Phaser 3, вид сверху. Диспетчер выдаёт одно из 5 заданий → на складе взять нужный предмет → заправиться → полететь к месту на карте → выполнить кнопкой действия → вернуться на площадку → медаль на «Доску героя». Когда собраны все 5 медалей — праздник и новый круг.

| Миссия | Предмет |
|---|---|
| Пожар в лесу | вода |
| Спасение в горах | трос |
| Засуха в саду | семена |
| Спасение на озере | спасательный круг |
| Ночная миссия | прожектор |

Управление: геймпад (стандартная раскладка Xbox / DualSense), клавиатура — стрелки/WASD + пробел.

Локальный запуск: `game/start.command` (macOS, двойной клик) или `python3 -m http.server 8765 --directory game`, затем http://localhost:8765/ — меню.

Интерфейс миссий описан в `game/MISSIONS.md`. Автотесты — `game/tools` (playwright-core + системный Chrome).

URL-параметры: `?mission=fire` — первым дать это задание, `?test=1` — без звука и без сохранения прогресса.

## Вторая игра: «Спасательный полёт» (`game/runner/`)

Раннер в духе Subway Surfers: вертолёт сам летит вперёд над тремя полосами (море, потом суша и снова море), ребёнок только перестраивается влево/вправо. Когда зверёк с табличкой SOS в твоей полосе, сам спускается спасательный круг (на воде) или крюк (на скале). Жёлтая подсветка полосы и стрелка показывают, куда лететь. Звёзды по пути собираются сами. Пропущенный зверёк появится позже, проиграть нельзя. Спасли 10 — радуга-финиш и праздник.

Управление: геймпад — крестовина, стик, LB/RB, LT/RT, X (влево) / B (вправо); клавиатура — ← → или A/D; тач — левая/правая половина экрана. Любая кнопка — старт.

Автотест: `node game/tools/runner-smoke.mjs /tmp/out` (сервер на 8765 из `game/`).

## Бумажная база (`build.py` → `out/`)

`python3 build.py` генерирует SVG базы и PDF для печати на A4 (нужен Google Chrome).
